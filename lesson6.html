Lesson 6: Methods

Methods are reusable blocks of code that perform a specific task.

Why This Lesson Matters

Every Java lesson builds a stronger foundation for writing real applications. These concepts are used every day in desktop, web, and mobile development.

  • Understand how Java works behind the scenes
  • Learn the syntax and structure clearly
  • Practice examples that translate directly into real projects
  • See how the lesson connects to larger programming concepts

Creating a Method

public static void greet() {
  System.out.println("Hello!");
}

Calling a Method

greet();

public class Main {

  public static void greet() {
    System.out.println("Hello Java!");
  }

  public static void main(String[] args) {
    greet();
  }

}
?

Key Takeaway

Methods are reusable blocks of code that help organize your program. They allow you to avoid repetition by writing code once and using it many times. Good use of methods makes your code easier to read, maintain, and debug.
