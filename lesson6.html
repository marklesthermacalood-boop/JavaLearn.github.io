Lesson 6: Methods

Methods organize code into named blocks that perform specific tasks. They make programs easier to read, test, and reuse by moving repeated logic into one place.

What you will learn

  • Define methods with parameters and return values.
  • Call methods from main and other methods.
  • Use methods to keep code clean and reusable.

Why this matters

Methods help you avoid duplicate code and make it easier to change one part of the program without breaking everything else.

Important concepts

  • Method — A named block of code that performs a task.
  • Parameter — A value passed into a method.
  • Return type — The kind of value a method gives back.
  • Call — Running a method from another part of code.
  • Static — A method that belongs to the class rather than to an object.
Example Code
public class Main {
  public static void main(String[] args) {
    greet();
    int sum = add(4, 6);
    System.out.println("Sum: " + sum);
    System.out.println("Is 7 even? " + isEven(7));
  }

  public static void greet() {
    System.out.println("Hello from a method!");
  }

  public static int add(int x, int y) {
    return x + y;
  }

  public static boolean isEven(int value) {
    return value % 2 == 0;
  }
}
💡

Key Takeaway

Methods break your program into reusable parts, making it easier to read and maintain.
