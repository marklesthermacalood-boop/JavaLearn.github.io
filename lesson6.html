Lesson 6: Methods

Methods organize code into reusable pieces. Each method performs one task, which makes your program easier to read and easier to fix.

What you will learn

  • Learn how to break programs into smaller parts.
  • See how methods make code reusable.
  • Understand parameters and return values.

Important concepts

  • Method — A named block of code that performs a task.
  • Parameter — A value given to a method.
  • Return type — The kind of value a method gives back.
  • Call — Running a method from another part of code.
  • Static — A method that belongs to the class itself.
Example Code
public class Main {
  public static void main(String[] args) {
    greet();
    int sum = add(4, 6);
    System.out.println("Sum: " + sum);
  }
  public static void greet() {
    System.out.println("Hello from a method!");
  }
  public static int add(int x, int y) {
    return x + y;
  }
}
?

Key Takeaway

Methods let you reuse logic and keep each part of your program focused on a single job.
