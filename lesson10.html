Lesson 10: Polymorphism

Polymorphism allows the same method call to behave differently depending on the object. It makes Java code more flexible and easier to expand.

What you will learn

  • See how one interface can support many object types.
  • Understand method overriding and dynamic behavior.
  • Write code that works with general types instead of specific ones.

Important concepts

  • Polymorphism — One action, many forms.
  • Inheritance — A subclass reuses a parent class.
  • Override — A subclass changes a method.
  • Superclass — The parent class.
  • Dynamic binding — Java chooses which method to run at runtime.
Example Code
public class Main {
  public static void main(String[] args) {
    Animal animal = new Dog();
    animal.speak();
    animal = new Cat();
    animal.speak();
  }
  static class Animal {
    void speak() {
      System.out.println("Animal sound");
    }
  }
  static class Dog extends Animal {
    @Override
    void speak() {
      System.out.println("Dog says woof");
    }
  }
  static class Cat extends Animal {
    @Override
    void speak() {
      System.out.println("Cat says meow");
    }
  }
}

Key Takeaway

Polymorphism helps your program work with many kinds of objects through a common interface.
