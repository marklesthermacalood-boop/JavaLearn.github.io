Lesson 4: If Statements

If statements teach Java how to make decisions. Your program can choose one path when something is true, and a different path when it is false.

What you will learn

  • See how Java uses conditions to control the flow of a program.
  • Use if, else if, and else to handle multiple outcomes.
  • Avoid common mistakes when writing boolean expressions.

Important concepts

  • if — Run code only when a condition is true.
  • else if — Check another condition when the first is false.
  • else — Run code when no conditions are true.
  • Condition — A true/false expression that decides what happens.
  • Boolean — A value that is true or false.
Example Code
public class Main {
  public static void main(String[] args) {
    int score = 75;
    if (score >= 90) {
      System.out.println("Excellent");
    } else if (score >= 60) {
      System.out.println("Good job");
    } else {
      System.out.println("Keep practicing");
    }
  }
}

Key Takeaway

If statements make your program smart by choosing what to do next based on true/false conditions.
