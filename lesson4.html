Lesson 4: If Statements

If statements allow your program to make decisions based on conditions.

Why This Lesson Matters

Every Java lesson builds a stronger foundation for writing real applications. These concepts are used every day in desktop, web, and mobile development.

  • Understand how Java works behind the scenes
  • Learn the syntax and structure clearly
  • Practice examples that translate directly into real projects
  • See how the lesson connects to larger programming concepts

Basic If Statement

if (condition) {
  // code runs if true
}

If-Else

if (condition) {
  // true
} else {
  // false
}

public class Main {
  public static void main(String[] args) {

    int age = 18;

    if (age >= 18) {
      System.out.println("Adult");
    } else {
      System.out.println("Minor");
    }

  }
}
✨

Key Takeaway

If statements let your program choose what to do based on conditions.
