Lesson 5: Loops

Loops let Java repeat actions many times without writing the same code over and over. They are perfect for counting, processing lists, and repeating tasks.

What you will learn

  • Practice repeating code efficiently.
  • Learn the three main loop types in Java.
  • Avoid duplicate code with loop logic.

Important concepts

  • for loop — Repeat a fixed number of times.
  • while loop — Repeat while a condition remains true.
  • do-while loop — Run at least once, then repeat while true.
  • break — Stop the loop immediately.
  • continue — Skip to the next loop iteration.
Example Code
public class Main {
  public static void main(String[] args) {
    for (int i = 1; i <= 5; i++) {
      System.out.println("Count: " + i);
    }
  }
}

Key Takeaway

Loops are a powerful tool for repeating code and working through multiple values quickly and clearly.
