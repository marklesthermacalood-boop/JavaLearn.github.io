Lesson 8: Strings

A String is used to store text in Java.

Why This Lesson Matters

Every Java lesson builds a stronger foundation for writing real applications. These concepts are used every day in desktop, web, and mobile development.

  • Understand how Java works behind the scenes
  • Learn the syntax and structure clearly
  • Practice examples that translate directly into real projects
  • See how the lesson connects to larger programming concepts

Example Methods

  • length()
  • toUpperCase()
  • toLowerCase()
public class Main {
  public static void main(String[] args) {

    String name = "Java";

    System.out.println(name.length());
    System.out.println(name.toUpperCase());
    System.out.println(name.toLowerCase());

  }
}

Key Takeaway: Strings are objects used to store and manipulate text.
