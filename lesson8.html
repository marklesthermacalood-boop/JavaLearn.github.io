Lesson 8: Strings

Strings hold text, like names or messages. Java treats strings as objects with helpful tools for joining, measuring, and changing text.

What you will learn

  • Work with text in your programs.
  • Use string methods to inspect and combine text.
  • Know the difference between String and characters.

Important concepts

  • String — Text inside quotes like "Hello".
  • Concatenation — Joining text with +.
  • length() — Find how many characters are in a string.
  • charAt() — Get one character by position.
  • equals() — Compare strings correctly.
Example Code
public class Main {
  public static void main(String[] args) {
    String first = "Java";
    String second = "Basics";
    String message = first + " " + second;
    System.out.println(message);
    System.out.println("Length: " + message.length());
    System.out.println("First char: " + message.charAt(0));
  }
}

Key Takeaway

Strings let you work with written text and Java gives you methods to manipulate that text safely.
