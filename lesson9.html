Lesson 9: Classes & Objects

Classes define the structure of objects, and objects are the things your program works with. This is the heart of object-oriented programming in Java.

What you will learn

  • Learn the relationship between classes and objects.
  • See how fields store object data.
  • Use methods to make objects perform actions.

Important concepts

  • Class — A blueprint that defines data and behavior.
  • Object — A specific instance created from a class.
  • Field — A value stored inside an object.
  • Constructor — Sets up a new object when it is created.
  • Method — A behavior the object can perform.
Example Code
public class Main {
  public static void main(String[] args) {
    Car car = new Car("Red", 2024);
    car.showInfo();
  }
  static class Car {
    String color;
    int year;
    Car(String color, int year) {
      this.color = color;
      this.year = year;
    }
    void showInfo() {
      System.out.println("Car: " + color + " " + year);
    }
  }
}

Key Takeaway

Classes and objects help you organize code around real-world ideas, making it easier to build bigger programs.
