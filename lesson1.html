Lesson 1: What is Java?

Java is a popular programming language that is easy to learn and used in many places, including websites, mobile apps, and enterprise systems. It is designed to run on many different computers without changing the code. This is possible because Java programs are compiled into bytecode and run by the Java Virtual Machine (JVM).

What you will learn

  • Learn how Java programs are structured before writing code.
  • Understand the compile-and-run process that makes Java portable.
  • See the difference between source code, bytecode, and the JVM.

Important concepts

  • Java Program — A set of instructions written in Java language.
  • Compilation — Turning Java code into bytecode using javac.
  • JVM — Runs the compiled code on any platform.
  • Class — The basic building block of Java programs.
  • main method — The starting point where the program begins.
Example Code
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello, Java!");
  }
}
?

Key Takeaway

Java programs start inside the main method and are portable because they run on the JVM instead of directly on the computer hardware.
