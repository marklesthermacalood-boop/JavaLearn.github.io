Lesson 1: What is Java?

Java is a powerful, platform-independent programming language used for desktop apps, mobile apps, servers, and more. It is designed to run anywhere through the Java Virtual Machine (JVM), which executes compiled Java bytecode on any supported platform.

What you will learn

  • Understand what makes Java portable and widely used.
  • Learn how Java source code becomes bytecode and runs on the JVM.
  • See the structure of a simple Java program and where execution begins.

Why this matters

Java is used in many real-world systems from Android apps to enterprise servers. Learning Java gives you a strong foundation in programming and helps you understand how many big applications work.

Important concepts

  • Java source code — Human-readable code written by a developer in a .java file.
  • Compilation — The process that turns Java code into JVM bytecode using javac.
  • Bytecode — Platform-independent instructions executed by the JVM.
  • JVM — Java Virtual Machine that runs bytecode on different operating systems.
  • main method — The starting point of a Java program: public static void main(String[] args).
Example Code
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello, Java!");
  }
}
💡

Key Takeaway

Java programs run inside the JVM and are portable across platforms because Java code is compiled into bytecode instead of machine-specific instructions.
