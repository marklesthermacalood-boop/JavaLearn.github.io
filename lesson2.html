Lesson 2: Variables & Data Types

Home > Lessons > Lesson 2

Variables are used to store data in Java. Each variable must have a data type that defines what kind of value it can hold.

Why This Lesson Matters

Every Java lesson builds a stronger foundation for writing real applications. These concepts are used every day in desktop, web, and mobile development.

  • Understand how Java works behind the scenes
  • Learn the syntax and structure clearly
  • Practice examples that translate directly into real projects
  • See how the lesson connects to larger programming concepts

Common Data Types

  • int – stores whole numbers (e.g., 10)
  • double – stores decimal numbers (e.g., 3.14)
  • char – stores a single character (e.g., 'A')
  • boolean – stores true or false
  • String – stores text (e.g., "Hello")
Example Code 
public class Main {
  public static void main(String[] args) {

    int age = 18;
    double height = 5.9;
    char grade = 'A';
    boolean isStudent = true;
    String name = "John";

    System.out.println("Name: " + name);
    System.out.println("Age: " + age);
    System.out.println("Height: " + height);
    System.out.println("Grade: " + grade);
    System.out.println("Student: " + isStudent);
  }
}
✨

Key Takeaway

Variables store data, and data types define what kind of values those variables can hold.
