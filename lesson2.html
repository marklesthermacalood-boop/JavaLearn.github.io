Lesson 2: Variables & Data Types

Variables store values that your program can use and change. Every variable has a data type, which tells Java what kind of information it holds and how much memory to reserve.

What you will learn

  • Learn how to declare variables and give them names.
  • Understand Java primitive types and common reference types like String.
  • Avoid common mistakes when using variable types and names.

Why this matters

Using the right data types helps Java catch errors early and makes your program faster and easier to maintain.

Important concepts

  • int — Stores whole numbers like 42 or -10.
  • double — Stores decimal numbers like 9.99.
  • boolean — Stores true or false values.
  • char — Stores a single character, such as "A".
  • String — Stores text. Strings are objects in Java.
Example Code
public class Main {
  public static void main(String[] args) {
    String name = "Alice";
    int age = 20;
    double score = 95.5;
    boolean passed = true;
    char grade = 'A';

    System.out.println(name + " is " + age + " years old.");
    System.out.println("Score: " + score);
    System.out.println("Passed: " + passed);
    System.out.println("Grade: " + grade);
  }
}
💡

Key Takeaway

Every variable in Java has a type, and choosing the right type makes your code safer and easier to understand.
