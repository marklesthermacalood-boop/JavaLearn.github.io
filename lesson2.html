Lesson 2: Variables & Data Types

Variables store information inside a Java program. Every variable uses a data type, which tells Java what kind of information it holds. This helps the computer use memory efficiently and avoid mistakes when the program runs.

What you will learn

  • See how data is stored and named in a program.
  • Learn the most common data types used in Java.
  • Understand why Java requires a type for each variable.

Important concepts

  • int — Whole numbers such as 10 or -5.
  • double — Decimal numbers such as 3.14.
  • boolean — A value that is true or false.
  • char — A single character, like "A".
  • String — Text stored inside quotation marks.
Example Code
public class Main {
  public static void main(String[] args) {
    String name = "Alice";
    int age = 20;
    double score = 95.5;
    boolean passed = true;
    System.out.println(name + " is " + age + " years old.");
    System.out.println("Score: " + score);
    System.out.println("Passed: " + passed);
  }
}
?

Key Takeaway

Variables hold values and each one must use the correct data type so Java can understand and process it properly.
