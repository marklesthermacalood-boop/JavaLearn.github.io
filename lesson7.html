Lesson 7: Arrays

Arrays are used to store multiple values in a single variable instead of creating separate variables for each value.

Why This Lesson Matters

Every Java lesson builds a stronger foundation for writing real applications. These concepts are used every day in desktop, web, and mobile development.

  • Understand how Java works behind the scenes
  • Learn the syntax and structure clearly
  • Practice examples that translate directly into real projects
  • See how the lesson connects to larger programming concepts

Example

int[] numbers = {1, 2, 3, 4, 5};

You access elements using index starting from 0.

public class Main {
  public static void main(String[] args) {

    int[] nums = {10, 20, 30};

    System.out.println(nums[0]);
    System.out.println(nums[1]);
    System.out.println(nums[2]);

  }
}

Key Takeaway: Arrays help store multiple values in one variable using indexes.
