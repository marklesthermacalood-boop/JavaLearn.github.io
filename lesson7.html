Lesson 7: Arrays

Lesson 7: Arrays

Arrays store multiple values under one name. Instead of separate variables for each item, arrays let you keep a whole list together and use loops to process it.

What you will learn

  • Keep lists of values in one place.
  • Access items by their position in the array.
  • Use loops to handle many values at once.

Important concepts

  • Array — A collection of values stored in order.
  • Index — The position of an item, starting from 0.
  • length — The number of items in the array.
  • Element — One value inside the array.
  • Traversal — Visiting each item with a loop.
Example Code
public class Main {
  public static void main(String[] args) {
    String[] fruits = {"Apple", "Banana", "Cherry"};
    for (int i = 0; i < fruits.length; i++) {
      System.out.println("Fruit " + (i + 1) + ": " + fruits[i]);
    }
  }
}
?

Key Takeaway

Arrays let you store and process multiple values in a simple, ordered way.
